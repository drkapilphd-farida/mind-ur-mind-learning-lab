# Mind Ur Mind Learning Lab™

## Exercise Specification Template v1.0

**Status:** Mandatory
**Governed by:** `PROJECT_RULES.md`, `LEARNING_BIBLE.md`

---

This is not an exercise. This is the blueprint every exercise must be written from.

To specify a new exercise, copy this file to `docs/exercises/<exercise-name>.md` and complete every section below. No section may be left blank. If a section is genuinely not applicable to a given exercise, write *"Not applicable — [reason]"* rather than deleting it. A specification is not complete until every section has either real content or a stated reason for its absence.

This document defines only the *shape* of a specification. It contains no exercise content of its own.

A specification written against this template is what authorizes implementation to begin — not the other way around.
