# Mind Ur Mind Learning Lab™

## Project Rules v1.0

---

# Vision

Mind Ur Mind Learning Lab™ is an AI-powered Cognitive Skill Training Platform designed exclusively for students.

It is not a Learning Management System (LMS).

It is not a course-selling platform.

It is not a quiz application.

Its purpose is to improve the way students learn.

The software should help students:

* Read faster
* Understand better
* Remember longer
* Focus deeply
* Learn efficiently

The experience must feel like daily brain training rather than attending an online course.

---

# Target Users

Age:

5+ years

Primary users:

* School Students
* College Students
* Competitive Exam Students
* Lifelong Learners

---

# Product Philosophy

The product teaches skills through practice.

Not through recorded lectures.

Users become better by doing exercises.

Every screen should encourage action instead of passive watching.

---

# Live Teaching Strategy

There will be NO recorded teaching videos inside the software.

Whenever deeper explanation is required, students will attend LIVE workshops conducted by Dr. Kapil Dev Sharma.

The software supports workshops.

The software never replaces workshops.

# AI Rules

AI should:

* Encourage
* Personalize
* Recommend
* Explain simply
* Motivate

* Shame
* Overwhelm

---

# Development Rules

Never build multiple modules together.

Build only one part at a time.

Every module must:

* Compile successfully
* Pass TypeScript
* Pass lint
* Be responsive
* Reuse existing components
* Maintain accessibility

Stop after every completed part.

Wait for review.

---

# Technical Principles

Reuse code whenever possible.

Avoid duplicate components.

Avoid duplicate business logic.

Keep architecture modular.

Maintain clean folder structure.

---

# Success Criteria

A successful Mind Ur Mind Learning Lab™ should make students say:

"I actually enjoy practicing."

"I am improving every day."

"I can read faster."

"I remember more."

"I stay focused longer."

"I want to come back tomorrow."

---

# Final Rule

Whenever there is uncertainty, choose the option that creates a better learning experience for students.

Student transformation always comes before software complexity.

This document is the permanent constitution of Mind Ur Mind Learning Lab™.

Every future feature, screen, component, prompt and AI interaction must follow these rules.
